# SafeShift Predictor - Frontend

Interfaz web para la visualización de turnos, gestión de riesgos por fatiga y reasignación de personal en tiempo real.

## Stack Tecnológico

- **Framework:** React + TypeScript + Vite
- **Estilos:** Tailwind CSS / CSS Modules
- **Iconografía:** Lucide React

## Requisitos Previos

- Node.js (v18 o superior recomendado)
- npm o pnpm
